# 작은성공 — 휴대폰 설치용 웹앱

## 1. 인터넷에 올리기 (GitHub Pages, 무료)
1. github.com 에서 새 저장소를 만들어요. 이름: `small-wins`, 공개(Public).
2. 저장소에서 **Add file → Upload files** 를 누르고, 이 폴더 안의 파일과 `icons` 폴더를 통째로 끌어다 놓은 뒤 **Commit changes**.
3. **Settings → Pages → Branch: main / (root) → Save**.
4. 1~2분 뒤 `https://<내 아이디>.github.io/small-wins/` 주소가 생겨요.

## 2. iPhone에 설치
1. 위 주소를 **Safari**로 열어요.
2. 공유 버튼 → **홈 화면에 추가**.
   - 잠금 화면(단축어) 기능까지 쓸 거라면, 추가 화면에 **웹 앱으로 열기** 옵션이 보일 때 꺼 두세요.
     iPhone은 홈 화면 웹앱과 Safari의 저장 공간을 따로 쓰기 때문에, 꺼야 기록이 한곳에 모여요.

## 3. 앱 열 때 카드 먼저 보기 (선택)
앱의 **잠금** 탭 → 앱별 **링크 복사** → 단축어 앱의 **자동화**에서:
1. **+ → 앱** → 막을 앱 선택 → **열릴 때**, **즉시 실행**
2. 동작 **메뉴에서 선택**: 항목 `카드 한 장 뽑기`, `그냥 열기`
3. `카드 한 장 뽑기` 아래에 **URL 열기** + 복사한 링크

## 알아둘 것
- 기록은 휴대폰 안(브라우저 저장소)에만 저장돼요. 서버로 보내지 않아요.
- 실제로 다른 앱을 '막는' 기능은 Apple의 Screen Time API가 필요해 유료 개발자 계정 없이는 만들 수 없어요. 단축어 자동화가 그 역할을 대신해요.
